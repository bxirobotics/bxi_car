# 松闸后手动调零

`start_yiyou_jog.sh` / `start.sh zero` 默认使用 `--control-mode manual`。
实际启动会接通驱动/抱闸共享电源，但全程不使能电机，也不发送位置、速度或转矩目标。
本次开发和验证只运行模拟测试及命令预览，没有实际上电、松闸或保存零位。

```bash
# 只预览，不访问硬件。
bash start_yiyou_jog.sh --dry-run --interface enp86s0 --slaves 1,2,3

# 准备好支撑机构后实际启动；会接通共享电源。
sudo bash start_yiyou_jog.sh --interface enp86s0 --slaves 1,2,3 --control-mode manual
```

操作顺序：

1. 托住机构，左右键选择站位。
2. 按 `b` 松开当前轴抱闸，用手缓慢摆到所需零位。一次只允许松开一轴。
3. 停稳后按空格，闭闸并恢复自动抱闸控制；完成前继续托住机构。
4. 按 `z` 保存当前轴零位。程序再次确认失能、抱闸参数和静止，再写零及EEPROM。
5. 等待保存完成后可选择下一轴；`q` 正常退出先闭闸，等待配置延时，再断电。

上下键在此模式下不发送运动指令。忙碌时按空格、Ctrl-C或断开终端会中止并走断电路径；
通信故障/必要反馈异常仍由原周期保护优先切断共享电源，不因等待抱闸或EEPROM而延迟。
松闸等待可响应取消；失败不自动重试或清驱动故障。

## 参数与保存

依据意优[官方通信手册V1.11](https://file.eyoubot.com/document/EYou-PHU%26RHU%E7%B3%BB%E5%88%97%E5%85%B3%E8%8A%82CANopen%E4%B8%8EEtherCAT%E9%80%9A%E4%BF%A1%E6%89%8B%E5%86%8Cv1.11-20261010.pdf#page=192)，印刷185–186页：

| 对象 | 类型 | 语义 |
| --- | --- | --- |
| 2110:00 | uint8 | 0手动控制；1随使能/失能自动动作 |
| 2111:00 | int8 | 1闭闸；0松闸 |
| 2113:00 | uint16 | 松闸动作延时ms，最大10000 |
| 2114:00 | uint16 | 闭闸动作延时ms，最大6500 |
| 2130:00 | uint8 | 写1保存当前参数 |

松闸顺序是先2111=1读回，再2110=0读回，最后2111=0读回；中途持续确认驱动失能。
闭闸顺序是2111=1读回、2110=1读回并等待配置延时。缺少对象、值非法、回读不一致或状态异常均退出断电。

2110/2111标为可持久化，设零会调用2130保存参数。因此保存前强制恢复并读回
**2110=1、2111=1**，不把临时强制松闸配置写入EEPROM。正常退出也恢复该自动闭闸配置。
原来的手动抱闸配置不会在退出时恢复；此校准工具明确使用自动闭闸作为结束状态。
第4轴已有专门的多圈位置限制，手动模式拒绝包含该轴的选择。

## 实物限制

RHU40H/RHU32H短型号不能确认带闸；厂家用户手册V1.25中B/N代表带闸/不带闸选配。
必须结合完整型号及实际机构确认，软件对象存在也不证明机械抱闸存在。
寄存器读回只说明驱动接受了指令，不是机械抱闸已经开合的反馈。
减速器可能不易反向推动，松闸后仍难以推动时不要硬扳。

松闸后机构可能因重力运动，需持续支撑。原100 N·m驱动反馈阈值保留，但未使能时
6077不是手推外力或输出端负载传感器，不能用它保证手动调节时的负载安全。
本工具不承诺抱闸动作时间、断电延迟或零点精度；这些仍需实机核验。

转矩调节可显式用 `--control-mode torque`，每键电机侧名义目标增减0.05 N·m；
位置点动可用 `--control-mode position`，每键100°；松开后完成当前步再保持位置，q / Ctrl-C 中止并退出断电。
显式指定 `--startup-retreat-slave` 的启动退让仍为1°。两者的使能及运动行为与手动模式不同。
