# Gemini 335 IMU 与第三轴校准参考

独立读取加速度计和陀螺仪，不启动彩色／深度图像流，不打开机器人控制接口，
不切换共享电源、不使能电机、不发送运动或写零指令。运行前退出占用同一相机的程序。
使用工程已有的 `pyorbbecsdk2` 环境；相机 USB 权限不足时可用 sudo 运行指定解释器。

```bash
sudo .venv-vision/bin/python tools/gemini_imu.py --seconds 8 \
  --output /tmp/car2-gemini335-imu.json

# 离线测试与帮助均不打开设备。
python3 -B test/unit/test_gemini_imu.py
python3 tools/gemini_imu.py --help
```

丢弃开始 1 秒的数据，再分别采集两种 200 Hz 数据流；设备缺少该配置时明确报错。
明显采样率异常、采集时长不足或时间戳大间断也会报错。
多台 Gemini 335 连接时用 `--serial` 选择。输出文件含原始数据、时间戳、设备序列号、
固件、采样率、单位、SDK 标定的 IMU→彩色相机旋转、均值和标准差。
SDK 诊断可能也出现在终端，机器读取结果应使用 `--output` 指定的 JSON 文件。

加速度单位 m/s²，角速度单位 rad/s。外参旋转按行主序计算 `a_color = R @ a_imu`，
方向向量不加平移。彩色光学坐标为 X 向右、Y 向下、Z 沿镜头向前。
镜头轴相对水平面的**绝对倾角**为：

```
inclination_abs = asin(abs(a_color.z) / norm(a_color))
```

`stationary_candidate` 仅检查采样量、波动、角速度和重力合量是否适合作静态参考，
不证明标定准确。`tilt_sign_verified` 固定为 false：单次采样不确认实机抬头／低头与
第三轴正转的关系，不得据绝对倾角直接下发带符号的位置补偿。重力也不能测量绝对 yaw。

## 本机的安装关系

标定前内置模型的20°初始姿态（关节 q 全为 0）：大臂从向后水平线上抬 20°，小臂上抬 54.69°，
第三段竖直向上。用户确认 Gemini 335 安装在第三轴末端，第三段竖直时镜头应水平朝前。
因此当前模型的工具方向与镜头方向约有 -90° 固定安装角，不能直接当成同一方向。
程序默认回位大臂向后上抬 30°、小臂朝前水平、模型工具竖直，镜头也应水平朝前。

几何模型使用 `pitch_tool = sum(q) + sum(zero_offsets)`。若底盘肩坐标相对水平的
俯仰为 `pitch_base`、镜头安装角为 `mount_pitch`，则有：

```
pitch_camera_world = pitch_base + sum(q) + sum(zero_offsets) + mount_pitch
mount_pitch ≈ -90°
```

先确认静止时三轴的编码器角、底盘倾斜和相机固定安装角，再确认第三轴补偿符号。
保持前两轴标定不变。若要校正运动学几何，只修正第三项几何偏置；若要改变启动回位，
还要相应计算第三项回位目标。电机 EEPROM 零位、主机零点计数、几何偏置和回位目标
含义不同，不能把同一个修正量重复加到多处。仅改几何偏置不会改变已有的关节回位目标。
该读取脚本不执行这些写入或运动。

2026-11-12 首次记录使用固件 1.4.60 的 Gemini 335，加速度计和陀螺仪在 8 秒内各采集 1617 帧。
加速度原始均值 `[-0.00795, 9.59230, 1.30087] m/s²`，合量 `9.68011 m/s²`。
应用设备旋转外参后镜头绝对倾角约 7.82°，单帧倾角标准差约 0.059°。
这次没有同步读取关节编码器，没有写入校准，不是水平零点记录。

后续已上电读取编码器，实际关节角约 `[-10.00,-115.31,125.31]°`，对应默认回位，
不能再根据先前口头描述把当前姿态当成 q 全为 0。仅第三轴完成一次正转 1°再返回：

| 状态 | 第三轴计数 | IMU 的 `atan2(az,ay)` |
| --- | ---: | ---: |
| 运动前 | 7299838 | 7.833706° |
| 正转约 1° | 7358091 | 8.846294° |
| 返回 | 7299837 | 7.834954° |

前两轴未下发运动目标，计数仅有约 1 脉冲波动；每圈为 20971520 脉冲。
这证实当前安装下减小第三轴关节角可使镜头靠近水平。
首尾平均读数与正转读数给出的局部响应约为 `1.011977°/°`，预测水平关节角约 `117.5684°`。
这是一度往返阶段得到的预测；后续实际到位的测量如下。
往返平均倾角差约 0.00125°不代表传感器的绝对准确度。
它也不能单独区分电机零偏、相机支架安装偏差与底盘倾斜。

## 已完成的第三轴调平

用户授权后，以 0.1 RPM 仅调整第三轴，目标计数为 `6848856`，对应关节角
`117.56840515136719°`。前两轴保持原位，未发送运动目标；没有写电机 EEPROM。

| 测量状态 | 静止采样时长 | 镜头轴平均倾角 |
| --- | ---: | ---: |
| 本次调整前 | 4 秒 | 7.844001° |
| 调整到位、保持使能 | 8 秒 | 0.032073° |
| 确认共享电源关闭后 | 8 秒 | 0.002345° |

两次到位测量均通过采样质量和静止候选检查，低于本次 0.2°验收目标。
这些是静态平均读数，不代表传感器的绝对准确度。

保存的回位关节角为 `[-10,-115.31,117.56840515136719]°`；
JSON 第三几何偏置为 `-0.4811594394151231 rad`（`-27.568405151367188°`）。
两者改变量相反，使回位模型工具 pitch 仍为 90°；前两轴偏置、方向和零点计数不变。
标定时本地和远端 YAML 分别加载了各自主机的 JSON。仓库随附的 YAML 从当前配置目录加载同一标定模型。
本地、远端实际 C++ 正逆解均已验证新配置的回位位置约为 `[0.140192379,0.15,π/2]`。

主控已恢复等待启动状态。本次没有运行整机启动、底盘标定或保存配置后的整机自动回位。
